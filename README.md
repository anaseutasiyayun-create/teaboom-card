# Карточка товара «Ананасовый улун»

Тестовое задание на позицию HTML-верстальщика в Teaboom.ru.

**Что:** верстка верхней части карточки товара интернет-магазина по товару «Ананасовый улун»: фото, категория, название, выбор фасовки, артикул, актуальная и старая цена, кнопка «В корзину», краткое описание.

**Для кого:** для команды Teaboom.ru, которая оценивает качество HTML и CSS, адаптивность, аккуратность и работу интерактивных элементов.

**Зачем:** показать, как карточка собирается без Bootstrap и готовых шаблонов, на чистых HTML5, CSS (Flexbox и Grid) и JavaScript, в стилистике сайта.

Страница: https://anaseutasiyayun-create.github.io/teaboom-card/

Локально: `index.html` в браузере, без сборки и установки.

## Структура

```
index.html
css/style.css
js/main.js
fonts/open-sans-cyrillic.woff2
fonts/open-sans-latin.woff2
img/pineapple-oolong.jpg
```

## Как это работает

Данные фасовок лежат в атрибутах `data-sku`, `data-price` и `data-old-price` у радиокнопок. При выборе фасовки `js/main.js` берёт их и обновляет артикул, цену и старую цену. Выбранная кнопка подсвечивается через `:checked`. Чтобы добавить фасовку, достаточно скопировать один из блоков `label` и поменять значения.

Кнопка «В корзину» меняется при наведении. По клику она на полторы секунды показывает «Добавлено ✓», корзина не подключена.

## Адаптивность

- 1440 px: две колонки, фото слева.
- 768 px: одна колонка, фото ограничено по ширине.
- 375 px: одна колонка, кнопка на всю ширину, фасовки в сетке 2×2.

Брейкпоинты в `css/style.css`: 1100, 860 и 480 px.

## Шрифт

Open Sans лежит в папке `fonts` и подключён через `@font-face`, поэтому страница выглядит одинаково и без интернета. Это вариативный шрифт: один файл на кириллицу и один на латиницу покрывают начертания от 400 до 700. В Open Sans нет знака ₽, его браузер рисует запасным шрифтом Arial.
